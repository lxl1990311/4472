### 严重 bug：单年代队伍整页空白（用户截图发现）
- 现象：抽到 Falcons 2026（或任何「该队仅 1 个年代」的队）时，球员卡与阵容条全不渲染。

### 只剩最后一席时重抽，可能抽到「全灰阵容」（用户报告）
- 现象：只剩 1 个空位时点「更换战队 / 更换年代」，偶尔抽到整队都是灰卡（已选 / 无空位），点不动；
  重抽次数却已经扣掉，等于白送一次。
- 复现方法：node 直接加载 `index.html` 的 script，DOM 全桩，纯逻辑跑；各 2 万局 + 最后一签：

  | 重抽方式 | 抽到无人可填 | 概率 |
  |---|---|---|
  | 固定年代换队 `drawSquad(null, era)` | 5 / 20000 | 0.025% |
  | 固定队换年代 `drawSquad(team, null)` | **94 / 20000** | **0.47%** |
  | 整签重抽 `drawSquad(null, null, avoid)` | 0 / 20000 | — |

- 根因：`drawSquad` 的三级兜底。严格集合（`squadUsable`＝**未用**且有空位）为空时，退到
  `collect(true)`，那条只判断「阵容里有人能填当前空位」——**不看这人是不是已经被选走了**。
  于是抽出来的签全是 dead 卡。固定维度的候选少，所以换年代最容易踩到。
- 修法三点：
  1) 抽完必校验：`while` 里从候选池随机取，`squadUsable` 不通过就丢掉继续抽（真·自动重抽），抽干为止；
  2) 池子抽干 → 返回 `false`，**保留原签**（不把界面抽成空），调用方不扣重抽次数；
  3) `S.notice` 承载提示文案，针对性引导换另一种重抽；`pickInto` 与抽签成功时清空。
- 验证：
  - 修复后三种场景各 2 万局：无人可填 **0 / 0 / 0**；
  - **变异测试**：把 `if(squadUsable(cand.team, cand.era))` 改成 `if(true)`，立刻回到 9 / 99 次
    → 证明这条校验不是假护栏；
  - 边界用例 4 条全 PASS：无人可填返回 false、原签对象引用保持不变、固定队全不可用返回 false；
  - 61 套阵容 + 2 万局完整流程回归：0 异常、0 空签；
  - Edge headless `--dump-dom` 渲染正常，无白屏。
- 数据现状：61 套阵容位置覆盖 100% 齐全（`selfCheck` 的 badFit=0），所以问题只在「候选人被抽干」的
  极端状态，不是数据缺位置。

### 对手只会抽到 Complexity / ENCE，Major 还会同站重复（用户发现）

- 现象：前五站的对手永远是 Complexity 和 ENCE；Major 春出现 `NIP · Virtus.pro · Virtus.pro`，同一站打同一个对手两次。
- 根因：`bracket()` 把 **0~1 的比例当成了数组下标**。
  ```js
  let i = RI(a, Math.max(a,b-1));   // a/b 是比例，如 0.45~1
  return pool[CLAMP(i,0,n-1)];      // 却直接拿 i 当索引
  ```
  `RI` 的上界最大只到 1，所以索引只可能是 `0` 或 `1`——永远取 pool 里最弱的两支队。
  去重循环 `while(used.has(i))` 在这两个索引之间来回抽，抽 12 次也跳不出去，于是 Major 三场必重。
- 实测（修复前，每站 1 万次）：

  | 赛事 | 池子 | 实际出现的对手 | 站内重复 |
  |---|---|---|---|
  | 达拉斯 | 4 支 | Complexity 100% / ENCE 100% | 0% |
  | MAJOR 春 | 10 支 | Virtus.pro 159% / NIP 141% | **100%** |
  | MAJOR 冬 | 8 支 | MOUZ 159% / Liquid 141% | **100%** |

- 修法：比例先换算成真实索引区间，再在区间内选空位。
  - `lo2 = floor(a*n)`、`hi2 = ceil(b*n)-1`（再夹到 `n-1`）；
  - 段内没有空位就放宽到全池，全池也没有才允许重复（池子比场次少）；
  - 删掉 `n < cnt` 时 `pool.concat(pool)` 的死板兜底。
- 修复后同口径实测：8 个赛事**全部覆盖整个池子**，站内重复 **0%**；梯度仍然是弱→强
  （MAJOR 春 81.8 → 86.2 → 89.2，MAJOR 冬 84.0 → 87.3 → 89.1）。
- 数据现状提醒：`TEAMS` 只有 16 支、pw 73~96，达拉斯这种低区间本来就只剩 4 支队可选。
  想更丰富得补队伍或加宽区间，不是算法能解决的。
