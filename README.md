# 大乱斗 · GOAT DRAFT

一个单文件网页小游戏：抽「战队 + 年代」，从该批选手里凑五个位置，定核心、选战术，然后模拟一整年赛事，看能拿几个冠军。

非官方粉丝同人作品，仅供娱乐。选手、战队、赛事名称仅用于统计与讨论，相关权利归各自所有者。

---

## 怎么跑

双击 `index.html`，浏览器直接打开，零依赖零安装。

## 一局的完整链路

```
抽 5 签（战队 + 年代，全局 3 次重抽）
  → 点人名 + 点位置（只剩一个空位时直接入位）
  → 选核心（资源倾斜，选错扣分）
  → 选战术（9 个，加强/削弱不同位置）
  → 8 站赛事（卡托、科隆、双 Major）
  → 战绩页：冠军数 + 球员赛季数据 + 赛季明细
```

## 数据结构

`SQUADS` 是「战队 → 年代 → 选手数组」三层结构，每条选手：

```js
{n:'s1mple', p:['awp','lurker'], r:1.36, c:'乌克兰'}
//  n 姓名 / p 可打位置（第一个是本职）/ r 评分 / c 国籍
```

位置键固定五个：`awp` `entry` `igl` `support` `lurker`。**每套阵容必须五位置齐全**，否则自检会报错。

## 数据来源与可信度

| 数据 | 来源 | 可信度 |
|---|---|---|
| HLTV 年度 TOP20（2014–2025，共 12 年） | `hltv.org/players/top20/<year>` | ✅ 官方，逐条核对 |
| 年度位置奖项（IGL/AWP/Opener…，2022 起） | `hltv.org/awards` | ✅ 官方 |
| 赛事冠军 / 亚军名单 | Major、IEM 卡托维兹、IEM 科隆 官方赛果 | ✅ 已核对 |
| 选手评分 `r` | **估算值** | ❌ 未逐人核对，界面已隐藏，仅用于后台计算 |
| 选手位置 `p` | 二手资料（HLTV 无位置字段） | ⚠️ 存在误差 |

已知缺口：2026 年无 TOP20 榜单，该年选手按评分估档。

## 改动时的三条规矩

1. **同阵容去重**：同一套五人只保留一条。跨年份、跨队名（Gambit→Cloud9、VP→Outsiders）都算重复。
2. **每套五位置齐全**：改完点首页「运行自检」，应显示「✓ 自检通过」。
3. **改完跑一遍分布**：基准分在 `calcResult` 里（当前 `62 + (avg-1.30)*130 + chemVal*2 + tacBonus + coreBonus`），
   数据量变化会让平均分漂移，需要重测后微调。
